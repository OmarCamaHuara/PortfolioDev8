# Learnings

Ao **fechar cada milestone**, criar aqui um arquivo `M?.md` com as lições da etapa. Sessões que rescopam o projeto de forma significativa (fora de milestone) também entram aqui, com nome no formato `YYYY-MM-DD-<slug>.md`.

## Template para learnings de milestone

```markdown
# Learnings — M? (<nome do milestone>)

**Período:** <data início> → <data fim> · **US executadas:** N/N

## O que funcionou bem
- <item>

## O que travou / surpreendeu
- <item — inclua estimativas furadas e por quê>

## Decisões que nasceram aqui
- <link para DECISIONS.md>

## Ajustes no processo/docs para o próximo milestone
- <item acionável>

## Nota para o "eu do futuro" (e para a IA da próxima sessão)
<1 parágrafo franco>
```
