# M6 — IA integrada (Edge Function)

**Objetivo:** as 2 frentes de IA defensáveis (chatbot sobre o perfil + pitch por vaga com aprovação humana) saem do papel como Route Handlers Edge do Next, com guardrails de injection, rate-limit real (Upstash Redis), cache por hash, provider `mock` para dev e disclaimer visível.

**Valor entregue:** diferencial máximo do portfolio com **engenharia responsável** — nada de LLM sem guardrail, nada de exibir output de IA como se fosse afirmação do próprio Omar.

## Critérios de conclusão do milestone

- Chatbot responde perguntas sobre o perfil com dados fiéis ao MDX de `content/`, no idioma da pergunta.
- Trocar `AI_PROVIDER` (env) muda de provedor sem tocar em código. Provider `mock` é o default em dev/CI.
- Rate-limit por IP + teto diário funcionam; modo sem IA sempre navegável.
- Pitch por vaga é gerado e **não exibido publicamente sem aprovação humana** (email pro Omar).
- Injection guardrails: allow-list de tópicos + sanitização + delimitadores + prompt sandwich.
- LGPD: consent banner + retenção 24h em Redis + zero PII em log.
