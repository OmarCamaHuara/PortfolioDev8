# M0 — Higiene + infra dev

**Objetivo:** limpar sobras do Vite, colocar infraestrutura de qualidade que suporta o resto do projeto (CI, a11y automatizada, formulário de contato sem chaves no cliente), e criar `AGENTS.md` como ponto único de entrada para sessões de IA.

**Valor entregue:** repositório pronto pra escalar. Qualquer US futura já nasce com CI validando, a11y testada e sem regressão silenciosa.

## Critérios de conclusão do milestone

- Nenhum resquício de Vite ou EmailJS com chave hardcoded.
- CI GitHub Actions roda em cada PR: build + lint + typecheck + testes axe.
- `AGENTS.md` na raiz existe e substitui a leitura de `CONSTITUTION` + `CONTEXT` + `SHARED_RULES` na abertura de sessão.
- Formulário de contato envia via Route Handler serverless (Resend/similar), sem chave no cliente.
